# Commands

This page lists every `repro` command, grouped by what it works on. Each
command's page gives its options, their defaults, its exit status, and what the
command changes:

- reads only: inspects and reports, and changes nothing;
- changes the working tree: writes files in your project or workspace;
- changes the workspace definition: edits the manifests, which you then commit for everyone;
- publishes: writes to a shared store or a remote.

`repro --help` prints the same list, and `repro <command> --help` the same
detail, because both are generated from one description of the command line.
