# Workspaces

These guides cover [workspaces](../../reference/glossary.md#workspace):
several repositories checked out side by side, built against each other.

| Guide | When |
|---|---|
| [Join a workspace](join-a-workspace.md) | You are setting a workspace up on a new machine |
| [Work on a dependency's source](develop-a-dependency.md) | You want to change a library and build its users against the change |
| [Build a flake against a local checkout of an input](develop-a-flake-input.md) | A flake's input is a repository you have checked out, and you want the flake to use your checkout |
