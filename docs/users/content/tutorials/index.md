# Tutorials

Each tutorial takes you along one path, from an empty directory to a working
result, and explains each step as you take it.

| Tutorial | What you do |
|---|---|
| [Build your first project](first-build.md) | Build a project with a library and a program, change the library, and add a package that reprobuild finds from your imports |
| [Move a project from a Nix flake to reprobuild](move-a-project-from-a-nix-flake.md) | Hand a flake project's environment and build to reprobuild one step at a time, then remove the flake |

To reach one goal without the lesson, go to the [guides](../guides/index.md).
